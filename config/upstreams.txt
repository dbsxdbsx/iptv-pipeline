# 上游成品直播源列表（每行一个 URL）
# 这些都是"别人已经跑好的聚合管道"的产物，本项目做的是"聚合聚合器"：
# 拉取 -> 解析 -> 归一化 -> 交叉去重 -> 验证 -> 统一产出。
#
# 语法：
#   - 每行一个 http(s) URL，指向 .m3u / .m3u8 播放列表或 .txt(#genre#) 列表
#   - 以 # 开头的行是注释；行尾也可用 " #注释" 附注（URL 中不含空格）
#   - 空行忽略
#
# 维护建议：某个上游长期失效时，在其行首加 # 停用而非直接删除，方便日后恢复。

# 上游 URL 一律优先写 GitHub raw 而非作者自建 CDN：
# 拉取发生在 GitHub Actions 里（raw 在那儿很快），而自建 CDN 是这份列表的主要腐烂来源
# ——fanmingming 的 live.fanmingming.cn 挂掉时，同一批内容在仓库里完好无损。
